# VeriFairy Legal Pages

This repository hosts the public legal pages for **VeriFairy**, a Discord application designed to help participating servers manage access to designated or age-restricted areas.

## Live Pages

- [Privacy Policy](privacy.html)
- [Terms of Use](terms.html)

## Purpose

These pages explain:

- What limited operational information VeriFairy processes
- What VeriFairy does not collect, including identity documents and other sensitive verification materials
- How third-party, user-selected verification providers fit into the verification process
- User responsibilities and rules for using VeriFairy
- How to contact VeriFairy with privacy or Terms-related questions

## Repository Contents

```text
index.html      # Landing page for the legal site
privacy.html    # VeriFairy Privacy Policy
terms.html      # VeriFairy Terms of Use
README.md       # Information about this repository
```

## Important Notice

This repository contains only public legal-page content.

Do not upload any of the following to this repository:

- Discord bot tokens
- API keys
- Webhook signing secrets
- `.env` files
- Database files
- User data
- Verification records
- Private bot source code
